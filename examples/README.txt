CyberLogParser örnek loglar
==========================

Bu klasörde 3 örnek dosya var:

1) apache_access.log
   - Apache/Nginx benzeri access log örnekleri

2) auth.log
   - Syslog/SSH kimlik doğrulama örnekleri (Failed/Accepted)

3) suricata_eve.json
   - Suricata EVE JSON (NDJSON: her satır 1 JSON obje)

Kullanım:
  - Uygulamayı aç:  python ..\\CyberLogParser.py
  - "Dosya Seç" → bu klasörden bir dosya seç
  - "Parse Et"
